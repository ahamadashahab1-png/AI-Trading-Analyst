# 2. BASIC DEFINITIONS

## 2.1 Support

Support ek price level ya zone hai jahan historical price action mein buying interest ya downward movement ka slowdown observe hua ho.

Possible behaviour:
- Price rejection.
- Buying pressure.
- Consolidation.
- Short covering.
- Trend continuation.
- Breakdown.

## 2.2 Resistance

Resistance ek price level ya zone hai jahan historical price action mein selling interest ya upward movement ka slowdown observe hua ho.

Possible behaviour:
- Price rejection.
- Selling pressure.
- Consolidation.
- Profit booking.
- Trend continuation.
- Breakout.

## 2.3 Support and Resistance Zone

Market mein reactions aksar ek exact price ke bajay price range ke andar hoti hain.

Isliye AI ko zaroorat ke hisaab se:
- Zone upper boundary.
- Zone lower boundary.
- Zone midpoint.
- Zone width.
- Historical reactions.

Record karne chahiye.

## 2.4 Acceptance and Rejection

Acceptance:
- Price kisi level ke beyond sustain karta hai.
- Multiple closes level ke beyond ho sakte hain.
- Retests level ko hold kar sakte hain.

Rejection:
- Price level ko test karta hai.
- Opposite direction mein move karta hai.
- Rejection candles ya displacement develop ho sakta hai.

Acceptance aur rejection ke rules strategy ke hisaab se define karo.

Exact zone boundaries ke liye defined methodology use karo.

Possible methods:

1. Candle body range.
2. Wick extreme.
3. Swing cluster.
4. ATR-based buffer.
5. Volatility-adjusted clustering.

## 7.1 ATR-based zone buffer

ATR = Average True Range.

True Range:

TR = Maximum of:

- High - Low.
- Absolute(High - Previous Close).
- Absolute(Low - Previous Close).

ATR ko selected lookback period ke according calculate karo.

Example conceptual formula:

Zone Buffer = ATR × Selected Multiplier

Multiplier strategy-specific parameter hai. Universal value claim mat karo.

## 7.2 Zone width

Zone Width = Upper Boundary - Lower Boundary

Zone width ko instrument tick size, ATR aur volatility ke comparison mein evaluate karo.

## 7.3 Zone midpoint

Zone Midpoint = (Upper Boundary + Lower Boundary) / 2

Midpoint informational reference hai, guaranteed reaction point nahi.

# 32. PYTHON IMPLEMENTATION

## 32.1 OHLCV validation

```python
def validate_ohlcv(df):
    required = [
        "open", "high", "low",
        "close", "volume"
    ]

    if df.empty:
        return False, "Dataset is empty"

    if not all(c in df.columns for c in required):
        return False, "Required columns missing"

    if not df.index.is_monotonic_increasing:
        return False, "Timestamps are not sorted"

    if df.index.has_duplicates:
        return False, "Duplicate timestamps"

    invalid = (
        (df["high"] < df["low"]) |
        (df["high"] < df["open"]) |
        (df["high"] < df["close"]) |
        (df["low"] > df["open"]) |
        (df["low"] > df["close"]) |
        (df["volume"] < 0)
    )

    if invalid.any():
        return False, "Invalid OHLCV values"

    return True, "Basic validation passed"
```

```python
import pandas as pd

def calculate_atr(df, period=14):
    if period < 1:
        raise ValueError("Period must be positive")

    previous_close = df["close"].shift(1)

    true_range = pd.concat(
        [
            df["high"] - df["low"],
            (df["high"] - previous_close).abs(),
            (df["low"] - previous_close).abs()
        ],
        axis=1
    ).max(axis=1)

    return true_range.ewm(
        alpha=1 / period,
        adjust=False,
        min_periods=period
    ).mean()
```

## 32.3 Basic swing-level extraction

```python
def detect_pivot_levels(df, left=3, right=3):
    if left < 1 or right < 1:
        raise ValueError("Invalid pivot settings")

    highs = df["high"]
    lows = df["low"]

    pivot_highs = []
    pivot_lows = []

    for i in range(left, len(df) - right):
        high_window = highs.iloc[i-left:i+right+1]
        low_window = lows.iloc[i-left:i+right+1]

        if highs.iloc[i] == high_window.max():
            if (high_window == highs.iloc[i]).sum() == 1:
                pivot_highs.append({
                    "pivot_time": df.index[i],
                    "confirmation_time": df.index[i + right],
                    "price": float(highs.iloc[i]),
                    "type": "RESISTANCE_CANDIDATE"
                })

        if lows.iloc[i] == low_window.min():
            if (low_window == lows.iloc[i]).sum() == 1:
                pivot_lows.append({
                    "pivot_time": df.index[i],
                    "confirmation_time": df.index[i + right],
                    "price": float(lows.iloc[i]),
                    "type": "SUPPORT_CANDIDATE"
                })

    return pivot_highs, pivot_lows
```

Important:
- Use confirmation_time for historical availability.
- Do not use a pivot before confirmation.
- This is a simple candidate generator.
- Production level clustering needs volatility and tick-size adjustment.

## 32.4 Basic level clustering

```python
def cluster_price_levels(levels, tolerance):
    if tolerance <= 0:
        raise ValueError("Tolerance must be positive")

    sorted_levels = sorted(levels)

    if not sorted_levels:
        return []

    clusters = [[sorted_levels[0]]]

    for price in sorted_levels[1:]:
        current_center = sum(clusters[-1]) / len(clusters[-1])

        if abs(price - current_center) <= tolerance:
            clusters[-1].append(price)
        else:
            clusters.append([price])

    return [
        {
            "lower": min(cluster),
            "upper": max(cluster),
            "midpoint": sum(cluster) / len(cluster),
            "observations": len(cluster)
        }
        for cluster in clusters
    ]
```

This simple clustering method is not a universal optimal method. Test alternative clustering algorithms and tolerance settings.
